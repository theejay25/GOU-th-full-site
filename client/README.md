# 📍 Gou‑Teaching‑Hospital Website

**Gou‑Teaching‑Hospital** is a responsive informational and
service‑oriented healthcare web platform built to showcase hospital
services, support patient interactions, and provide resources for
students and staff.

## 🌐 Live Demo

https://gouth.vercel.app/

## 🚀 Overview

This project represents a modern healthcare landing page for a teaching
hospital designed to: - Inform visitors about departments and
offerings - Enable online appointment booking - Support student and
training portals - Provide emergency and patient service details - Share
contact information and resources

## 🧠 Features

-   Home page with hero section
-   Departments section
-   Students & training section
-   Emergency services
-   Patient services
-   Contact section
-   Login system
-   Appointment booking button

## 🧾 Technologies & Tools

-   HTML
-   CSS
-   JavaScript
-   Netlify (deployment)
-   Git/GitHub
